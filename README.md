# Zin Exchange — MMK ⇄ THB

This repository contains the initial responsive UI preview for Zin Exchange.

## Deploy on Vercel
1. Upload these files to the root of a new GitHub repository.
2. Import that repository into Vercel.
3. In Vercel Project Settings → Build and Development Settings, select **Other** as the framework preset.
4. Leave Build Command and Output Directory empty. This is a static HTML site.
5. Deploy.

## Important
- This is a UI preview only. It does not yet store customer data or process real exchange transactions.
- Exchange rates intentionally start blank; do not enter or use fabricated rates.
- Do not add Firebase secrets or private keys to this repository.
- Firebase Authentication, Firestore security rules, Storage, owner setup, real transaction workflows, and Excel export must be implemented and tested before production financial use.
- This project is standalone and must not be connected to any legacy database or customer records.
